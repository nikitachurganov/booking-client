# Связь компонентов Ant Design Vue в коде с Figma

Таблица связывает компоненты `ant-design-vue`, которые используются в клиенте бронирования, с компонентами библиотеки **Ant Design Vue (Community)** в Figma. Code Connect не используется: связь держится на ссылках.

- **Тег в коде** — компонент так, как он написан в шаблоне Vue.
- **Где в коде** — каждая ссылка ведёт на строку, где компонент используется.
- **Компонент в Figma** — ссылка на экземпляр библиотечного компонента в секции «7. Компоненты Ant ↔ код» на странице «Прототип (актуальный)». Чтобы открыть исходный компонент в библиотеке, выделите экземпляр и выберите *Go to main component*.
- **Документация** — страница компонента на antdv.com.

Файл Figma: [Бронирование (клиент)](https://www.figma.com/design/s0DOnDqJJQTY1n9U2eS1vV/%D0%91%D1%80%D0%BE%D0%BD%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5--%D0%BA%D0%BB%D0%B8%D0%B5%D0%BD%D1%82-?node-id=1681-976)
